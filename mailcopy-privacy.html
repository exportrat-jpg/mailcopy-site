Yandex Sent Copy

Политика конфиденциальности Yandex Sent Copy

Эта политика описывает обработку данных локальной программой Yandex Sent Copy (MailCopy Windows), предназначенной для внутреннего копирования отправленной почты из Яндекса в Gmail. Страница описывает приложение, а не обработку данных посетителей основного сайта.

Какие данные обрабатываются и зачем

Для создания копий программа получает из папки «Отправленные» Яндекс Почты содержимое новых писем: заголовки, адреса отправителя и получателей, даты, текст и вложения. Эти данные передаются только в выбранный владельцем ящик Gmail. Письма не отправляются повторно первоначальным получателям.

Разрешение Google на чтение сообщений даёт техническую возможность читать сообщения аккаунта. Программа использует его для проверки адреса подключённого аккаунта и поиска копии по идентификатору и служебному заголовку после неоднозначного результата загрузки. Разрешение на добавление писем используется для сохранения копий в Gmail.

Где хранятся данные

Программа выполняется на компьютере владельца. Пароль приложения Яндекса, секрет OAuth-клиента и токен обновления Google хранятся локально с шифрованием Windows DPAPI для пользователя, выполнившего настройку. Данные писем обрабатываются в оперативной памяти; отдельный локальный архив содержимого писем программой не создаётся.

Локальная база состояния содержит идентификаторы писем, контрольные суммы, служебные метки и результаты копирования. Журнал работы содержит время проверок, идентификаторы и результаты операций, без текста писем, вложений и секретов. Журнал автоматически ротируется. База состояния сохраняется до её удаления владельцем; её удаление может нарушить защиту от повторного копирования.

Передача и использование

Письма передаются между сервисами Яндекс и Google по зашифрованным соединениям. У приложения нет отдельного облачного сервера для хранения почты. Данные не продаются, не используются для рекламы или обучения моделей искусственного интеллекта. Программа не пересылает полученные из Google данные другим сервисам.

Использование и передача информации, полученной через Google APIs, соответствуют Google API Services User Data Policy, включая требования Limited Use. Данные используются только для описанной пользователю функции копирования и проверки копий.

Как остановить доступ и удалить данные

Владелец может отключить задачу YandexSentCopy в Планировщике заданий Windows, отозвать доступ приложения в настройках аккаунта Google и отозвать пароль приложения в Яндекс ID. Для удаления локальных данных после остановки программы можно удалить её зашифрованные реквизиты, базу состояния и журналы из рабочей папки MailCopy.

Отзыв доступа и удаление программы не удаляют оригиналы в Яндексе и сохранённые копии в Gmail. Их хранением и удалением управляет владелец соответствующего почтового ящика.
